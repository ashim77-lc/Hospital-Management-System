# 🏥 Hospital Management System

A web-based Hospital Management System built with Python Flask, SQLite, and Bootstrap 5.

## 🚀 Live Demo
[[PythonAnywhere]](https://ashimcodes.pythonanywhere.com/)

## ✨ Features
- Secure login/register with password hashing (Werkzeug)
- Patient management — add, edit, delete, search
- Appointment booking with doctor, date, time, reason
- Mark appointments as completed with one click
- Dashboard with total patients, today's appointments, pending count
- Responsive UI with Bootstrap 5

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** Bootstrap 5, Jinja2
- **Security:** Werkzeug password hashing

## 📦 Installation

```bash
git clone https://github.com/ashim77-lc/Hospital-Management-System.git
cd Hospital-Management-System
pip install flask werkzeug
python database.py
python app.py
```
